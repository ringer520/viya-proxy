# 证书操作、区域访问控制、多语言与资源监控

本轮仅修改源码、编译并更新本地预览，不发布到 Debian 或公网面板。

## 功能与操作逻辑

1. SSL「申请与自动续期」每条记录提供编辑、克隆和删除。编辑允许更新名称、验证方式、邮箱及 DNS 凭据；域名是证书身份，不允许直接改名。克隆复制参数并留空域名，提交前输入新域名。删除继续确认，正在被相同域名的自动 HTTPS 站点使用时拒绝删除。
2. 添加封禁支持「指定 IP / 网段」和「禁止境外 IP（仅允许中国大陆及内网）」。后者同时覆盖 IPv4 / IPv6，保留回环、私网、链路本地及运营商 NAT 地址。仍支持到期和编辑，规则随完整配置备份保存。
3. 每个站点用 iOS 风格滑动开关直接启用/停用。请求期间禁用开关；服务端比较 version，防止旧页面覆盖新配置；应用失败显示错误和重新应用入口。未匹配/停用站点返回 404，避免 Caddy 默认空 200 被误认为仍在线。
4. 登录右上角和设置的外观页均提供「简体中文 / 🌐 English」。未设置偏好时跟随浏览器语言。选择保存在 viya-language，切换重新加载以统一所有组件。翻译使用明确的词典与格式化函数，不修改渲染后的 DOM；用户输入的站点名称、备注和日志内容保留原样。
5. 运行概览先展示服务器资源仪表，再展示服务可用性/延迟卡片，然后是站点流量与管理入口。CPU / 内存 / 磁盘均采集服务器真实数据；磁盘指 Viya 数据目录所在文件系统，不是所有磁盘容量之和。资源每 5 秒刷新，服务端缓存 3 秒，CPU 采样窗口 300ms；遵循面板自动刷新和后台暂停设置。不可用时展示缺失状态，不伪造百分比。仪表 90% 以上用警示色，兼容减少动态效果偏好。

## 区域控制的边界与更新

区域数据来自 APNIC 的 CN 已分配/已指派 IPv4/IPv6 网段，是注册分配地近似值，不是精确实时 IP 地理定位；不含港澳台，不保证 VPN、跨境网络或 CDN 的实际物理位置。UI 明示该边界。

Caddy 使用直接 TCP 对端 remote_ip 判断，不信任可伪造的 X-Forwarded-For。站点经 CDN 或其他反代访问时，判断的是代理节点地址，可能阻挡合法访问；启用前需确认链路。本轮没有自动信任代理请求头。

源码内置本次快照，运行不依赖第三方查询接口，不上传访问者 IP。维护者可运行 `python scripts/update-cn-ranges.py` 更新官方数据后重新构建。完整配置导入恢复区域规则，实际网段采用目标安装版本内置快照。
