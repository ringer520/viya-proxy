# Viya 排布与易用性整理

## 页面逻辑

主导航保留“概览、网络服务、安全与证书、运行维护”的层级，每个入口负责单一功能。页面顶部统一显示标题、简短说明、更新时间和主要操作。列表内不再重复提供相同刷新按钮；添加子域名和上传已有证书保留在其上下文位置。

Web 服务按“监听选项卡 → 搜索和状态筛选 → 全部站点流量摘要 → 主域名分组”组织。HTTP 和 HTTPS 点击切换，端口检测结果就近展示。流量摘要统计全部站点，筛选只影响列表；对应操作说明明确解释范围。

DDNS 按“任务名称与记录 → 地址来源与周期 → 当前解析地址 → 错误 → 备注与上次执行时间”组织。自动更新与手动更新分别提供入口，关闭自动调度仍可手动执行。长 IPv6 允许换行，不再重复展示同一地址。

## 功能说明与列表

每个页面提供默认折叠的操作说明。Web、DDNS、四层转发、DNS 凭据、证书及 IP 封禁支持关键词搜索；Web、DDNS、四层转发支持状态筛选。无匹配结果会明确提示清除筛选，避免被误认为数据丢失。表单中的域名、上游、路径、证书及端口说明统一用直接可执行的语言。

## 字体与排版

使用本机系统字体，不依赖远程字体请求。正文与输入框以 14px 为主，说明以 12–13px 为主，统一行高和表单间距；域名、地址与错误允许换行。数字使用等宽数字特性，地址按需使用代码字体。优化浅色、深色标题与说明文字对比度。

## 交互与可访问性

编辑、新建和确认弹窗共用焦点管理指令：打开后进入弹窗，Tab/Shift+Tab 在弹窗内循环，关闭后恢复焦点，多层弹窗共享页面滚动锁。编辑弹窗点击外侧保持打开；日志保留悬浮图标预览逻辑。为列表项目补充可访问分组名称，操作按钮补充可访问标签；提供跳到主要内容链接及减少动画的系统偏好适配。

设置保留左下角呼出、右侧抽屉、明确关闭按钮、快捷键及移动端适配。修改端口和密码单独提交，浏览器偏好即时保存。
