# Viya v0.3.1

## OpenWrt 启动修复
- 修复 procd 启动脚本多次设置环境变量造成相互覆盖的问题。
- 正确传入面板监听地址、数据目录、主密钥路径及 Caddy 程序路径，避免只监听 127.0.0.1 和找不到 Caddy。
- Linux amd64、arm64、armv7 安装包重新打包，包含修复后的 OpenWrt 启动脚本；Docker 镜像同步发布。

## 使用说明
- 全新 OpenWrt 安装可继续使用 README 中的一键安装命令。
- 安装器会保留已有启动脚本。已有 OpenWrt 安装如遇此问题，需要备份并替换 /etc/init.d/viya 为本版本 deploy/openwrt/viya 后重启服务。
- OpenWrt 的 LuCI 通常占用 80 端口，Web 服务监听端口需避开冲突。该冲突与面板端口 8181 无关。
- 修复后的启动脚本已在 ImmortalWrt x86_64 上确认面板局域网访问、Caddy 就绪及自启动配置；其他架构尚未真机验证。
