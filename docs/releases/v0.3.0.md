# Viya v0.3.0

## 界面与统计
- Web 服务和 TCP/UDP 转发分别展示近 30 天的总量、单项上下行和趋势，不再混合两类数据。
- 点击概览 Web 错误率可按站点和 HTTP 状态码定位异常，查看对应近期保留日志；不将状态码直接判定为攻击。
- 设置新增“清空所有统计”，需确认后重新计数；保留业务配置和原始日志，并避免旧归档重计。
- 修复设置表单被浏览器自动填入导致反复提示放弃修改的问题，移除底部未保存提示。
- 重设计版本更新卡片，保留更新进度和重启后自动刷新。
- 新增三套原创二次元主题及配套侧边栏、导航、按钮和动效；移除顶部主题横幅。
- SSL 关联使用统一放到信息末行，与 DNS 凭据保持一致；精简凭据重命名、IP 列表搜索和日志暂停入口。

## 稳定性与安装
- 加强配置应用回退、数据库迁移保护、备份校验及恢复检查，补充操作摘要和访问限制确认保护。
- DDNS 提供更新阶段、地址比较与回读结果；转发显示实际监听状态，DNS 凭据支持只读验证。
- 修正失败请求同时产生错误日志和访问日志时的后续统计重复计数。
- Linux 一键安装改进下载进度、重试、超时、端口冲突与升级回退；增加隔离安装流程测试。
- 通用入口支持 OpenWrt 分流，提供专用 procd 安装器、持久化目录、版本固定、校验与备份。

## 升级说明
- 升级前建议备份数据目录和主密钥。Linux amd64/arm64/armv7 安装包和 Docker 镜像由本标签构建。
- 本版数据库版本为 5；保留现有账户、站点、DNS 凭据、证书、DDNS 和访问安全规则。
- 月度统计是滚动近 30 天；异常定位只使用当前保留的详细访问记录，次数可能少于完整统计。旧版已记入的重复次数不会自动修订，确认清空统计后才从新起点计数。
- OpenWrt 不支持 MIPS；实际设备须满足持久化存储、可用空间及 HTTPS 证书要求。
