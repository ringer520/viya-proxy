# Viya v0.7.2

本版本修复配置导入清空流量统计、日志流断线漏行、外网升级在 Python 3.6 主机上中断等问题，并补齐安装脚本的镜像回退、低速熔断与备份轮转。

## 流量统计与配置

- **导入配置不再清空统计**：导入会整体替换站点列表，外键级联会把 `traffic_hours` 与 `site_error_hours` 一起删掉。现在导入成功后按站点引用回写运行期统计，已被导入删除的站点不再保留。
- **`automatic_https.skip` 按监听器计算**：此前按整个站点列表计算，HTTP 副本的域名会让 HTTPS server 也跳过 TLS。现在按监听器分组，只跳过该监听器真正提供 HTTP 的域名。
- **外部文件根统一为只读**：文件编辑器此前允许写入外部根，而站点文件 API 拒绝写入；两者现已一致。

## 日志与自更新

- **日志流续传按行定位**：SSE 此前把整批末尾的偏移作为 `Last-Event-ID`，重连只补回最后一行。现在每行使用自己的字节偏移。
- **镜像前缀不再重复拼接**：`install.sh` 兜底时会把镜像前缀加到已带前缀的 URL 上（生成 `https://ghproxy.nethttps://…`），二进制下载也完全忽略了 `GH_PROXY`；现在统一定义、还原 GitHub 原址并跳过刚失败的镜像。
- **校验和改为多数投票**：自更新不再采信最先响应的镜像，按多数镜像公布的值校验；出现分歧只记录告警，不会让所有下载都校验失败。

## 安装与升级（本版本重点）

- **兼容 Python 3.6**：CentOS 7、Rocky 8、阿里云 Linux 2 等发行版的 `python3` 仍是 3.6，此前升级会在 `==> Installing` 阶段因 `add_subparsers(required=True)` 抛 `TypeError` 中断。备份工具已回到 3.6 标准库，并在缺少 `sqlite3.Connection.backup` 时改用单事务 `iterdump` 重放；安装器前置校验 Python ≥ 3.6，过旧时只输出一行说明。
- **镜像探测前移，覆盖 OpenWrt**：镜像探测原本在 OpenWrt 分支之后，路由器只能直连 `raw.githubusercontent.com`。现在探测在分支之前执行，`install-openwrt.sh` 自身也具备多镜像回退；镜像列表统一为 `ghfast.top`、`ghproxy.net`、`gh-proxy.com`，并补齐 `raw.githubusercontent.com` 的兜底改写。
- **低速熔断**：Release 包下载新增 `--speed-limit 30720 --speed-time 20`，速率连续 20 秒低于 30 KB/s 立即断开并切换镜像，不再靠 `--max-time 600` 苦等十分钟；`wget` 分支补上 `-T 20` 停滞超时。
- **`sudo` 不再二次下载**：以本地文件运行时（`curl -o install.sh && sh install.sh`）直接 `sudo sh "$0"` 复用该文件；`curl | sh` 管道场景仍只能重新拉取，这一点保留原逻辑。
- **备份自动轮转**：Debian 与 OpenWrt 安装器均只保留最近 3 份安装快照（`/var/backups/viya/installer-*`、`/opt/viya/backups/install-*`），避免小容量路由器升级几次就写满磁盘。

## Docker

- 镜像内置 `HEALTHCHECK`（探测 `/api/v1/health`，端口取自 `VIYA_LISTEN`）。
- 仓库根目录新增 `docker-compose.yml`，与 README 的 Docker 配置一致，可直接 `docker compose up -d`。

## 升级说明

无 schema 变更（仍为 8）。systemd 安装可重跑 `install.sh` 或在「面板设置 → 版本与更新」中自更新；Docker 拉取新镜像即可。
