# Viya v0.7.0

本版本聚焦全链路稳定性、安全性与界面交互细节修复，精简冗余逻辑，并统一采用点击弹窗方式查看 Web 服务与四层转发日志。

## 安全与控制平面修复

- **信任代理与会话边界一致性**：
  - 统一受信任代理的 `X-Forwarded-Proto` 与 `X-Forwarded-For` 解析顺序及大小写处理，`cookieSecure`、登录限速、登录审计与访问防护均严格按多级请求头最右受信任跳识别。
  - 修复仅凭 `upstreamTargetsPanel` 回环或全网卡监听误放行同端口外部上游域名的问题，并修复 IPv6 Host HTTPS 重定向缺括号与空 Host 问题。
  - 修改密码输入错误的当前密码时改返回 HTTP `400`（不再误触发 `401` 登出会话）；只读账号获取告警配置时对 Webhook 密钥路径脱敏，同时「测试通知」改为同步等待实际投递结果后再返回状态。
  - 响应头 CSP 放行 `blob:` 图片预览，配合文件预览失败提示与样式类替换内联属性。
- **文件管理、压缩包与配置导入导出加固**：
  - 静态文件 `extractZip` 改用流式 `LimitReader` 实时统计解压总字节数以拦截 ZIP 炸弹与整数溢出，并在建目录/写文件前校验符号链接；`listSiteFiles` 同步校验符号链接并按只读角色返回 `writable`；大文件上传自动延长读写超时并及时清理 `MultipartForm` 临时文件，`mkdir` 非法 JSON 返回 `400`，下载响应头改用 `mime.FormatMediaType`。
  - 修复存在文件共享（`files`）站点时配置导入和恢复回滚校验报错的问题，并在导入/回滚后自动刷新访问控制与封禁策略缓存；静态/文件站点删除检查合并 `files` 类型并统一由引擎确认加载后的延迟清理链路处理。
  - 修复单管理员环境下无法将只读账号提升为管理员以及编辑不存在用户 ID 返回 200 的问题；支持测试 `https://` 上游时的实际 TLS 握手及 SNI 校验。
- **引擎规则、日志与自更新可靠性**：
  - 为 IP/CIDR 封禁及允许/拒绝名单 403 响应补充 `X-Viya-Access-Rule` 标记避免自封禁重载循环，并为允许/拒绝名单补充站点路径前缀匹配；全局/域名限流未填窗口时自动补全 `"1s"`。
  - 修复通配符自动证书删除时误删根域名证书目录的问题；修复损坏的历史 `.log.gz` 阻塞全局流量入库的问题；`siteAccessLogs` 兼容首次启动无日志文件及通配符域名匹配；异常定位与 30 天趋势统一采用客户端本地时区切分。
  - 在线自更新改用持久化数据目录流式暂存压缩包、缩短校验文件超时并确保镜像回退不发生切片别名错乱，且校验失败自动继续尝试备用节点。
  - 其它后端稳定性改进：`streamLogs` 过滤非访问日志与单次读取分块上限、`systemMetrics` 请求解耦与 panic 防卡死、OpenWrt MIPS 下 UDP socket 识别、DDNS 网卡选中 IP 校验与 IPv6 规范化比对、四层端口冲突检查对齐当前面板监听设置、文件站点诊断与 `tls.*` 证书日志精确匹配。

## 前端交互、国际化与界面优化

- **点击式日志弹窗统一与交互完善**：
  - 移除站点与端口转发列表的悬浮日志预览气泡及设置项「悬浮日志显示条数」，精简相关状态与样式；升级四层转发日志支持在统一弹窗中点击查看、手动刷新与自动刷新。
  - 修正弹窗叠放（`BanModal` 置顶于日志弹窗之上）、`SiteFormModal` 关闭不泄漏残留错误到主页面、`SiteFilesDrawer` 捕获阶段 `Escape` 处理与 `busy` 锁定。
  - 修复站点 / 四层规则触发 502 部分保存后的版本号（`version`）与子域名/路径同步问题，避免修正后重试保存命中 `409`；补全登出/会话失效时的全局状态、草稿口令、缓存流量与监听器状态清理。
- **按页加载、只读权限与视觉对比度**：
  - 拆分 `traffic` 与 `security` 刷新域并修复部分失败污染 `loadedScopes` 的问题，确保直达端口转发、站点与 DNS 凭据页时数据完整；`ServiceTrafficCell` 30 天折线图对齐本地时区，修复非 UTC 时区显示全零的问题。
  - 全面补齐只读（`viewer`）角色在证书、封禁、文件中心、配置备份与文件抽屉页的按钮禁用与写保护；文件上传 XHR 支持 `401` 会话过期检测。
  - 修正深色主题下日志级别徽标（`WARN`/`ERROR`）与多处状态文字对比度、英文模式 DDNS 行网格对齐、`LogWorkspace` 跟随面板刷新间隔、`SiteFilesDrawer` 完整站点对象透传，以及多处死代码与残留样式清理。
- **双语翻译补全**：扩展 `check_i18n.py` 以静态解析带插值的 `tr` 模板字符串，并补全所有前端与新增后端提示词条的英文翻译（缺失翻译为 0）。
