# Viya v0.5.1

## 服务器信息

- 「服务器监控」头部新增「系统」一项，显示发行版与版本（例如 `Debian 12`），位置在「运行时长」左边，悬停可查看内核版本、架构与主机名。
- 之前这里只有 `linux`——取自进程的运行平台，在所有 Linux 上都是同一个值，等于没有信息。现在改为读取发行版自身的 release 信息，Docker 部署下显示镜像的系统。
- 该系统信息在进程生命周期内只读取一次；读取失败会在下次采样重试，不会永久留空。

## 界面精简

- 动态 DNS 列表从 6~8 行压到 4 行：状态、上次检查、上次修改合并成一行，错误信息连同失败阶段和检查时间也合并成一行，不再重复三遍；「上次修改」只在实际改过 DNS 时出现。
- 动态 DNS 编辑表单去掉「备注」字段。该字段不影响任何行为，此前只会在列表里显示成一行「备注：viya」；已有记录的值保留，接口不变。
- 顶栏「引擎正常」右侧的刷新按钮移除，位置让给 GitHub 仓库入口。原来这个图标只在概览页标题栏出现，现在每个页面都能点。页面本身有自动轮询与各页面自己的刷新入口，顶栏这颗是重复的。
- 侧边栏「Web 服务」的数字角标移除，列表页自己有计数，且列表加载失败时该角标会停在旧值上。

## 主题

- 三套二次元主题（sakura / neon / lunar）移除页面标题背后的毛玻璃底板。它用负边距铺开，左边缘落在内容栅格之外、右边缘在屏幕中间渐隐，每个页面看起来都是一个没对齐的空框。标题现在直接叠在壁纸上，改用背景色柔光保证可读性。

## 性能

- 静态资源返回 `ETag`，重复访问返回 304 而不是重新下载整个文件；gzip 与原始表示各带自己的 ETag，`assets/*` 长期缓存，其余走协商缓存。

## 文档

- README 精简：移除界面状态细节等产品内说明，删掉只对维护者有用的打包流程，压缩安装与 OpenWrt 段落；新增官网入口，中英文两版保持一致。

## 升级说明

- 无数据库结构变更，可直接升级。
- `/api/v1/system-metrics` 新增 `host` 字段（发行版、版本、内核、架构、主机名），旧前端忽略即可。
- Linux amd64 / arm64 / armv7 安装包与多架构 Docker 镜像同步发布。
