# Viya v0.4.0

## 服务器文件管理器
- 新增「文件服务」页：目录树、面包屑导航、上传、新建文件夹/文件、图片与文本预览、下载、在线文本编辑。
- 默认只读运行（`VIYA_FILES_READONLY=1`），只读模式下所有写操作直接返回 403，而不是把 EROFS/EACCES 抛给用户；需要写入时须显式关闭该开关，并自行放宽 systemd 的 `ReadWritePaths`。
- 文件系统错误映射为可读结果：无权限与只读文件系统 → 403，路径不存在 → 404。
- WebDAV 配置改为独立对话框，不再混在站点表单里。
- 该入口默认隐藏，可在面板设置的「显示文件服务」开关里打开；关闭时导航自动隐藏，停留在该页会跳回概览。

## 站点能力
- 路径重写：支持剥离匹配前缀（`strip_prefix`）与改写为固定路径（`rewrite_to`），对所有站点类型生效。
- 上游调优：`streaming` 关闭响应缓冲，SSE 与逐字输出即时到达浏览器；另加连接与响应头超时配置。
- 维护模式：终端 handler 换成 503 页面，鉴权、响应头与限流仍然生效；维护提示文案会做 HTML 转义。
- 文件服务类型站点：同一目录同时提供网页浏览与 WebDAV，写权限关闭时写方法返回 405 并带 `Allow` 头，便于客户端区分「策略拒绝」与「资源不存在」。

## 性能
- 静态资源启用 gzip（进程内缓存，只压一次）：面板 JS 从 227 KB 降到 70 KB。
- 带内容哈希的资源使用 `immutable` 长缓存，其余为 `no-cache`，并正确下发 `Vary: Accept-Encoding`。
- 前端页面组件改为按需加载，首屏包体明显下降。
- 清理 353 条无效 CSS 规则（样式表 232 KB → 199 KB）。

## 升级说明
- 数据库新增列在启动时幂等补齐，旧版本直接升级，无需手工迁移。
- 仓库不再跟踪 `internal/web/dist`（构建产物）。从源码构建请先执行 `pnpm --dir web build`，否则 `go build` 会因 `go:embed` 找不到文件而失败。
- Linux amd64 / arm64 / armv7 安装包与 Docker 镜像同步发布。
