# Viya v0.7.1

本版本聚焦网页端在线自更新下载速度与容错体验优化，解决直连 GitHub 受限环境中升级缓慢或长时间卡死的问题。

## 在线更新加速与熔断优化

- **并发智能测速与镜像优选**：
  - 将在线更新候选源扩展至 `GH_PROXY`（若配置）、官方直连、`https://ghfast.top/`、`https://ghproxy.net/` 与 `https://gh-proxy.com/` 并自动去重。
  - 取消串行逐一试探 `sha256sums.txt`，改为并发发起短超时测速（单节点响应头超时 3 秒、总探测窗口 4 秒）；首个有效节点响应后开启 350 毫秒收集窗口，按实际端到端延迟升序排列全部候选下载源，避免被“小文件勉强能下、大文件极慢”的线路误导。
- **低速主动熔断与快速回退**：
  - 为大文件下载配置 15 秒首包响应头超时及 10 秒零进度停滞超时。
  - 新增 5 秒滑动平均速率检测：在经过 5 秒预热期且仍有备用镜像可供切换时，若持续平均速率低于 `150 KB/s`，将主动断开当前慢速连接并立即切换至下一候选镜像；若已回退到最后一个可用源，则自动放开低速限制以保证弱网下仍可完成更新。
- **测试覆盖**：新增并发镜像测速优选、低速主动熔断回退以及停滞超时的单元测试。
