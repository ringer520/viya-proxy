# Viya v0.5.2

这次发布主要是内部整理和两处用户可见的修复，功能面没有新增。

## 修复

- **错误提示不再中英混排**。此前只有英文的校验失败会翻译成中文，反向的情况一直存在：文件服务、面板访问、备份恢复、自动更新这几块的 206 条提示只有中文，英文界面里会突然出现一句中文。现在两侧都补齐了，切到英文后表单和横幅里的提示全部是英文。
- **部分英文错误原来会原样显示**。275 条校验文案改为中文键并登记英文词条，中文界面看到的是「站点 ID 无效」而不是 `invalid site id`。
- **直达某一页时，弹窗里的下拉可能是空的**。按页加载只统计了页面自身渲染的数据，没算弹窗要用的列表：直接打开动态 DNS、SSL 证书或 Web 服务页时，DNS 凭据和自定义证书没有加载，弹窗却提示「请先添加 DNS 凭据」。现在这些页面会连同弹窗依赖一起加载。
- **快速切页可能白屏**。页面加载用的是全局锁，切页太快时后一页的请求会被直接丢弃，页面一直空着直到来回切换；改为按页面去重。

## 性能

- **进入面板不再一次拉十个接口**。按页面加载后，直达动态 DNS 页只需 4 个数据请求，Web 服务页只拉站点、流量、健康状态和它要用的凭据/证书。写操作后的刷新仍是全量。
- **数据库连接池从 1 放到 4**。原来一条 5 秒一次的资源采样会把所有读请求排在它后面；并发读写压测（24 读 + 6 写）下 1440 次读取、36 次建、36 次删，没有出现 `SQLITE_BUSY`，p95 45 ms。`busy_timeout` 与外键校验改为随连接下发，否则新开的连接既不等待锁也不校验外键。

## 内部整理

- `main.go` 从 1718 行拆成路由、Caddy 监督、站点、校验、应用队列、HTTP 工具六个文件，`main.go` 只剩 312 行装配。
- 站点的 39 列读取、37 列写入合并为一处声明 + 生成语句，WebDAV 保存也改走同一入口；新增字段不再需要改四个地方，漏改也不会静默丢值。附带一个逐列往返的测试。
- 前端 `useHosts` 从 1032 行拆出监听器编辑与域名工具，`SiteFilesDrawer` 抽出预览面板与上传流程，对外接口与 `import` 路径未变。
- 八个被压成一行的全局样式表展开，diff 可读；纯空白改动，逐主题截图核对无变化。
- 浏览器冒烟新增断言：直达动态 DNS 必须请求它弹窗需要的凭据列表，且不请求无关分组。

## 升级说明

- 无数据库结构变更，可直接升级。
- Docker 与安装包同源，多架构镜像（amd64 / arm64 / armv7）同步发布。
- 英文界面下，浏览器自带的必填气泡仍跟随浏览器语言，这部分不在本次范围内。
