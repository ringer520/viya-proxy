# Viya v0.6.10

这一版为反向代理站点新增了**上游 Host 请求头**与**上游 TLS 证书域名（SNI）**配置，解决诸如 Cockpit WebSocket（`/cockpit/socket`）、多虚拟主机、CDN 回源以及内网 IP HTTPS 证书校验等场景下的 `Host` / SNI 不匹配问题（[#2](https://github.com/ringer520/viya-proxy/issues/2)）。

## 反向代理支持自定义上游 Host 与 TLS SNI

- **上游 Host 请求头（`upstream_host`）**：在站点编辑弹窗的「上游调优」中新增「上游 Host 请求头」，支持填写自定义域名（如 `app.internal`、`app.internal:8443`）或安全占位符（`{http.request.hostport}`、`{http.request.host}`、`{http.reverse_proxy.upstream.hostport}`、`{http.reverse_proxy.upstream.host}`）。配置后将在 Caddy `reverse_proxy.headers.request.set.Host` 中生效；留空则保持现有默认行为。
- **上游 TLS 证书域名 / SNI（`upstream_tls_server_name`）**：当上游地址为 `https://` 时，可在「上游调优」中指定上游 TLS 握手的 `server_name`（对应 Caddy `reverse_proxy.transport.tls.server_name`）。上游填内网 IP 时可借此指定证书域名以完成严格校验，留空则继续沿用上游地址的主机名。
- **严格校验与自动清理**：服务端校验拦截非法的空格、换行、通配符或未在白名单内的占位符；当站点切换为非反向代理类型或上游改回 `http://` 时自动清理不适用字段。

## 网络安装体验优化

- **国内加速镜像回退**：[install.sh](../../install.sh) 与 [deploy/install-openwrt.sh](../../deploy/install-openwrt.sh) 支持 `GH_PROXY` 环境变量，并在 GitHub Release 直连受限或中断时自动切换至镜像节点重试下载。

## 升级注意

- `proxy_hosts` 表启动时通过幂等补列自动添加 `upstream_host` 与 `upstream_tls_server_name`（默认空字符串），平滑兼容旧版数据库与配置导入导出，无需手工迁移。
