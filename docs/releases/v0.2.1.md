# Viya v0.2.1

This release improves list navigation and makes Linux self-updates observable and more reliable.

## Highlights

- Move Web services, TCP/UDP forwarding and Dynamic DNS search and status controls into their page headings. Expanding search keeps the other controls in the flow.
- Normalize the ERROR severity size in application logs.
- Show update download progress and update stages in Panel Settings. After the service restarts, the page waits for the health endpoint and refreshes automatically.
- Allow the `viya` service account to replace the installed binary during self-update. The systemd write path and Debian installer ownership now match that update flow.
- Keep the existing error detail when the main executable cannot be replaced.
- Rewrite the Chinese-first README and provide a complete English README with current install, Docker, migration, backup, restore and uninstall guidance.

## Downloads and containers

GitHub Actions builds Linux archives for `amd64`, `arm64` and `armv7`, publishes SHA-256 checksums, and builds the matching multi-architecture Docker image. The `latest` Docker tag is updated by the release workflow.

## Upgrade notes

- Linux systemd installations can update from Panel Settings. Back up important data before upgrading.
- Docker installations must pull and recreate the container. Keep the persistent data directory and its `master.key`.
- This release does not require a database migration.
