# Viya v0.5.0

## 面板访问控制

- 新增「面板访问」设置卡片，只有一个开关：**禁止从公网用 IP 打开面板**。开启后，用公网 IP 访问面板在登录前即返回 403，域名与局域网 IP 不受影响。
- 允许的域名**不需要手工维护**：从站点表里自动推导「上游指向面板自身」的站点，10 秒缓存，新增站点无需重启。未登记的域名同样拒绝，因此把任意域名解析到本机也无法绕过。
- 本机发起的连接（回环地址或本机网卡地址）始终放行，SSH 隧道可用于误配置恢复。判定要求连接方与解析后的真实客户端同时为本机，只信任连接方会让 Caddy 反代后的请求全部被当成 `127.0.0.1`。
- 保存前用当前请求回放新规则，会把自己锁死的配置直接拒绝并给出提示，而不是保存后才失去入口。
- 高级选项保留精确控制：允许的域名清单、允许的来源网段、强制 HTTPS（308 跳转并去掉端口）。
- **该开关默认关闭**，升级后行为与之前一致，需要时在「面板设置 → 访问与安全」中开启。

## 站点表单

- 「剥离访问路径前缀」与「重写路径」合并为一个互斥的「上游路径处理」下拉：保持原样转发 / 剥离访问路径前缀 / 重写到固定路径。之前两者同时填写时后者会静默覆盖前者，界面毫无提示。
- 未填写访问路径时不再显示「剥离前缀」选项，避免出现一个永远不可选的灰色项；清空访问路径会自动退回「保持原样转发」。
- 分组归位：删掉把路径字段与 HTTPS 段落包在一起的 section；「启用此站点」并进「站点状态」；上游请求头与连接选项合并为一张「上游调优」卡片，与「访问控制与安全」使用同一种折叠样式。
- 必填字段标 `*`，取消逐字段的「（选填）」；重复的说明文案合并。
- 「允许 WebDAV 写入」在未开启 WebDAV 时直接隐藏，不再显示为灰色不可点。
- 修复上游连通性测试按钮与结果文字重叠：按钮不再被压缩，长结果换行显示。
- 「将发布」摘要拆成两行，重试按钮改为「配置已保存，重新应用」。

## 升级说明

- 无数据库结构变更，旧版本可直接升级。
- 面板访问开关默认关闭，升级后访问方式不变。开启前请确认已能通过域名打开面板，否则保存会被拒绝并提示。
- 服务器文件服务维持只读；需要更大的可见范围时，按文件服务权限文档调整 systemd 与 ACL，不需要改动程序。
- Linux amd64 / arm64 / armv7 安装包与多架构 Docker 镜像同步发布。
