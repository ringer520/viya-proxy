# Viya v0.5.3

这一版没有功能改动，补的是「发布前没人守」的三件事：漏翻的英文文案、没有自动化的前端逻辑、以及发布说明与安装命令的版本号。功能面和数据库结构都与 v0.5.2 一致，可以直接升级。

## 修复

- **英文界面里仍有 32 条中文**。v0.5.2 补齐了 206 条后端提示，但没有工具拦住新漏的。这次把前端 `t("中文")` 里 22 条、后端 `errors.New` / `fmt.Errorf` 里 10 条一次性补完，`en.json` 从 2108 条增到 2140 条。典型位置是流量卡的「上行 / 下行」、访问控制的「IP 白名单 / IP 黑名单」、文件服务与 WebDAV 的说明文字，以及「服务器内部错误，请查看运行日志」「结束时间不能早于开始时间」这类校验提示。

## 测试与门禁

- **前端有了第一条自动化回归**。此前 `web` 下没有测试框架，唯一的前端自动化是那一个 Playwright 冒烟脚本，最容易回归的逻辑（按页加载、部分保存重试）全靠它守着。新增 vitest + 9 个用例，覆盖三处：
  - 直达动态 DNS 页只发 5 个请求，其中包含弹窗依赖的 `dns-providers`、且不请求无关的 `ip-bans`；从概览进过后再进动态 DNS 则零请求；两页并发时后一页不被丢弃（v0.5.2「快速切页白屏」的回归点）。
  - `502 configuration_pending` 部分保存后出现「重新应用」提示，成功后提示清除。
  - 域名工具函数：通配符与大小写归一、子域判定、`example.co.uk` 这类双标签后缀的注册域提取、图标色兜底。
- **漏翻现在会让构建失败**。新增 `scripts/check_i18n.py`，同时扫前端 `t()` / `tr` 字面量与后端可展示的中文错误串。为避免误报，它排除 `${}` 运行时插值、`%` 格式串与 HTML 片段；`en.json` 里未被静态引用的键只做报告、不判定失败（这些来自动态拼接和后端格式化消息）。
- **发布前校验 README 版本号**。两份 README 各有 2 处 `VERSION=vX.Y.Z` 安装示例，之前打标签时没人检查它和标签是否一致，忘了改就会让用户按 README 装到旧版。新增 `scripts/check_release_version.py`，在 `release.yml` 打包前断言 4 处全部等于 `github.ref_name`。

## 文档

- `docs/项目说明.md` 不再自称「发布版本 v0.3.0」，改为主体对应 v0.3.0、当前发布以 `docs/releases/` 为准，并修正 `applyLocked()` 已从 `main.go` 移到 `cmd/viya/config_apply.go` 的旧路径，附录标为历史。
- README 的从源码构建章节补上 `go test ./...`、`pnpm --dir web test`、`check_i18n.py` 三条命令。
- `.gitignore` 注释不再引用并不存在的 `Makefile`。

## 升级说明

- 无数据库结构变更，无 Caddy 配置格式变更，可直接覆盖升级。
- Docker 与安装包同源，多架构镜像（amd64 / arm64 / armv7）同步发布。
- 新增的检查只作用于仓库与 CI，运行时依赖没有增加。
