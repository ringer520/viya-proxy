# Viya v0.6.9

这一版为反向代理站点新增了**跳过上游 TLS 证书校验**选项，解决反代内网自签名 HTTPS 服务（如 PVE、ESXi、群晖、软路由管理后台等）时因证书不受信任导致 502 的问题。

## 支持跳过上游自签证书校验

许多内网服务默认启用了 HTTPS，但使用的是自签名证书或私有 IP 证书，之前 Caddy 代理在握手阶段会直接拒绝并向访客返回 `502 Bad Gateway`。

v0.6.9 起：

- **自动感应显示开关**：在新建或编辑反向代理站点时，只要上游地址填写 `https://`，表单下方会自动显示「跳过上游 TLS 证书校验（适用于内网自签证书）」复选框（默认关闭）。
- **内网放行，外网不降级**：该选项仅作用于 Viya（Caddy）与内网目标设备之间的回源握手，向编译后的 Caddy `transport.tls` 注入 `insecure_skip_verify: true`；外部访客与面板/站点之间仍保持合法受信任的 HTTPS 证书连接。
- **状态自动清理**：当站点切换为非反向代理类型或上游地址改回 `http://` 时，服务端会自动重置该开关，避免残留无效配置。
- **数据库兼容**：`proxy_hosts` 表启动时自动补列 `upstream_skip_tls_verify`（默认 `0`），平滑兼容旧版数据库与配置导入导出。

## 升级注意

- 启动时通过幂等列补充自动添加 `proxy_hosts.upstream_skip_tls_verify`，无需额外迁移操作。
- 默认行为保持严格校验不变，仅对明确勾选该选项的 HTTPS 站点生效。
