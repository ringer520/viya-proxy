# Viya v0.2.0

Viya v0.2.0 expands site management and strengthens recovery, access control and Linux installation. This release also simplifies Docker persistence to a single data directory.

## Highlights

- Manage static site files from the panel, including upload, browse, download, rename and delete operations.
- Configure URL redirects and refine proxy site metadata and file workflows.
- Improve configuration export, import, backups and recovery diagnostics.
- Add login throttling and security response headers; improve IP ban controls and site diagnostics.
- Improve server and traffic monitoring, logs, panel settings, and English-language interface coverage.
- Allow the first administrator to be created from any reachable IP. Keep the panel behind a trusted network or firewall until setup is complete.
- Make the Debian installer verify release checksums, detect occupied panel ports, preserve backups and recover the previous service after an unsuccessful upgrade.
- Make the systemd panel reachable from the LAN by default and print available panel URLs after installation.
- Simplify Docker persistence to one mounted directory containing the database, Caddy data, certificates, site files, logs, settings and master key.

## Downloads

GitHub Actions attaches `viya-linux-amd64.tar.gz`, `viya-linux-arm64.tar.gz`, `viya-linux-armv7.tar.gz` and `sha256sums.txt` to this release. It also builds and publishes the matching multi-architecture Docker image as `ringer520/viya-proxy:v0.2.0` and updates `ringer520/viya-proxy:latest`.

## Upgrade notes

- Back up your installation before upgrading. Read the Linux installer and backup/restore sections in the README.
- Docker users upgrading from the previous two-volume layout must copy their existing `master.key` into the persistent data directory before starting this image. Follow the README section **Migrating from the previous two-volume Docker setup**; otherwise saved DNS credentials cannot be decrypted.
- The new Docker Compose example binds one host directory, `/opt/viya/data`, to `/var/lib/viya`. Keep this directory and its `master.key` between upgrades.
