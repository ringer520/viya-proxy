# Viya 十项功能：方案与验收

本轮仅本地实现、编译和预览，不发布到 Debian。预览使用独立数据目录 `.preview/data`，不读取线上配置。

## 统一逻辑

监听拥有稳定 ID，站点绑定监听 ID，而不是仅按 HTTP / HTTPS 全局筛选。同一个域名可以存在于不同监听中，各自修改规则；日志和流量按监听与站点分别归属。旧配置迁移保留站点 ID 和统计数据；旧的同协议共享监听会在迁移时复制旧规则以保留访问行为。

证书标识由后端统一计算：仅 HTTP、指定上传证书、SSL 显式托管、匹配泛域名、单独自动申请或内部证书。自动证书列表从站点与本地公开证书元数据生成，不额外创建强制申请任务，避免干扰泛域名复用策略。标识依据当前配置与本地证书元数据，不通过外网 TLS 探测验证实际握手证书；引擎缓存中已有证书可能影响即时选择。

## 完整配置范围和恢复步骤

导出包含：DNS 加密凭据及其恢复所需密钥、Web 站点和监听、四层转发、DDNS、封禁、托管证书请求、上传证书与私钥、Caddy 证书存储、监控、面板设置、配置历史，以及当前浏览器的 `viya-*` 偏好；管理员用户名与密码哈希、登录会话不在导出范围内。备份整体使用 scrypt（N=32768, r=8, p=1）派生密钥和 AES-256-GCM 加密，导出时须设置至少 8 位备份密码，密码不会保存在服务器，遗失后该文件不可解密。

登录会话、访问日志、流量和监控采样不是配置，不在导出恢复范围中。启动环境参数、systemd / Docker 配置和操作系统设置需要目标部署自行管理；它们不属于面板可编辑配置。恢复后的面板监听端口在下次重启后生效。

导入先解密并预览范围，明确确认后自动保存导入前恢复快照。在事务中恢复配置，将 DNS 凭据重新加密为目标安装的主密钥，校验证书路径、监听及站点绑定，然后应用 Caddy。失败时恢复原数据、文件和引擎配置。浏览器偏好采用替换恢复。免密码的旧版 v3 文件仍可导入，导入后会提示改用加密导出。

## 已完成验证

- 前端类型检查和生产构建通过；Go 单元测试通过，增加迁移、独立复制、加密 / 篡改 / 路径验证和错误恢复相关测试。
- 真实本地 Caddy + Viya 接口验证：空白监听零继承、完整导入后独立修改、加密导出 / 检查 / 恢复、错误密码拒绝、用户名修改、恢复后重新登录、泛域名与单独证书分类。
- 跨安装密钥场景：备份中的 DNS 凭据以另一主密钥加密，导入后可用当前主密钥正确解密。
- 保留端口冲突恢复：导入试图占用面板端口时被拒绝；原监听、账户会话和 Caddy 状态恢复。
- 浏览器验证：两页无搜索、Web 展开搜索、唯一新增入口层级、空白端口表单、SSL 自动证书列表、配置入口在历史之前、监控真实在线 / 离线及可定制项。
- 窄屏 390px 检查 Web 和监控无页面横向溢出。

## 本地检查

地址：`http://127.0.0.1:18765`。独立演示账户：`admin` / `ViyaLocal2026!`。

预览 Web 监听使用 18443 / 18080，避免占用常用端口；测试域名使用本地 CA，停用的 `standalone.example.com` 仅演示独立申请标记，不向公网发起申请。示例 DNS 凭据没有真实 Token。

需要重新启动时运行 `scripts/start-local-preview.ps1`；需要重编译本地可执行程序时先停止本地预览，再运行 `scripts/start-local-preview.ps1 -Build`。
